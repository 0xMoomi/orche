Commit your work on your branch; do not push, merge or rebase: after your done passes the gate Orche pushes the branch and opens the PR. In a team repository you never push: your done ends at the commit and the ledger row, and the branch is pushed on the owner's word. Run VERIFY yourself, paste its output and record the ledger row for HEAD. The merge queue refuses a commit that changes code and carries `[skip ci]`. It also refuses a change to payments, auth, migrations, deploy, wallets or keys, or one of more changed lines than `review.deep_lines` (400 unless the project sets it), unless a test in this branch exercises the one fact it is safe because of. Add that test, and write the fact on a report line `SAFE: <fact>`.
