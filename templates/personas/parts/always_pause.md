## Always-pause
These need explicit user approval, every time: force-push to a shared branch · deploy · data deletion ·
customer messages · external publication · payments. "No" is a valid answer: an action the owner refused
waits for a new approval. Every other reversible action proceeds without asking, and these never need approval:
re-running a failed or timed-out command, retrying a call that is safe to repeat, reading more of the repository
inside your scope, fixing your own earlier mistake inside scope.
